# P.S ENTERPRISES – Inventory PWA

## New inventory workflow
1. Add each item once in Products with category, purchase rate, sale rate, pieces per carton and low-stock alert.
2. In Purchase, select the saved product; its purchase rate fills automatically. Saving the purchase increases stock.
3. In Sales, select the saved product; selling rate and available stock fill automatically. Saving a sale reduces stock.
4. Sales are blocked if quantity exceeds available stock.
5. Edit saved product rates in Products. Stock value, low-stock alerts, history, reports, CSV export and JSON backup are included.

## Install
Host all files on an HTTPS static host, then open the HTTPS link in Chrome on Android and choose menu > Install app / Add to Home screen. A PWA needs HTTPS to install and use offline caching. Opening index.html directly from a ZIP is not enough.

Data is stored locally in the browser on the phone. Backup regularly. GST calculator is an estimate only and does not file returns or determine legal liability.
